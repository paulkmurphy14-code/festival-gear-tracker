# Festival Gear Tracker - Quick Start Guide

Get up and running with Festival Gear Tracker in 5 minutes!

## For Festival Owners

### Step 1: Create Your Festival (2 minutes)

1. **Sign up** at the Festival Gear Tracker app
   - Enter your email and password
   - Confirm email (check inbox/spam)

2. **Create Festival**
   - Enter festival name
   - Add registrar name and contact details
   - Set start and end dates
   - Click "Create Festival"

3. **Two default locations created automatically:**
   - Band Registration Area (Purple)
   - Tags Not Collected (Red)

### Step 2: Invite Your Team (2 minutes)

**Quick Method:**
1. Click "User Management"
2. Click "Invite User"
3. Enter email and select role:
   - **Admin:** Can manage gear, locations, schedule (recommended for supervisors)
   - **User:** Can scan and manage gear (recommended for volunteers)
4. They receive email invitation
5. They sign up and join automatically

**Bulk Method (for many users):**
1. Prepare CSV: `Name, Email, Role`
2. Click "Bulk Upload CSV"
3. Select file and confirm
4. All receive invitations

### Step 3: Add Locations (1 minute)

1. Click "Locations"
2. Click "Add New Location"
3. Name it (e.g., "Main Stage", "Storage Tent")
4. Pick a color for visual identification
5. Save

**Repeat for all your venue areas**

### Step 4: Optional - Upload Schedule

If you have a performance schedule:
1. Prepare CSV: `Band Name, Location, Date (DD-MM-YYYY), Time (HH:MM)`
2. Click "Schedule"
3. Click "Upload Schedule CSV"
4. Select file and confirm

**Done!** You're ready to start registering gear.

## For Admins

Your festival owner has invited you. Here's how to get started:

### Step 1: Accept Invitation (30 seconds)

1. Check email for invitation
2. Click invitation link
3. Sign up with email and password
4. You're automatically added to the festival

### Step 2: Register Your First Band's Gear (2 minutes)

1. Click "Register" on home page
2. Enter band name (autocomplete helps)
3. Add items:
   - Type descriptions manually, OR
   - Use "Quick Add Instruments" for common items
4. Select initial location (default: "Band Registration Area")
5. Click "Register Items"
6. **Print QR codes immediately:**
   - Click "Print QR Codes" on success screen
   - Choose layout (Small Tags recommended)
   - Print and attach to equipment

### Step 3: Learn to Scan (1 minute)

1. Click "Scan QR" on home page
2. Allow camera access (one-time)
3. Point at QR code
4. Choose action:
   - **Check In:** Move to new location
   - **In Transit:** Mark as moving
   - **On Stage:** Currently performing
   - **Check Out to Band:** Return to band

**That's it!** You can now manage gear throughout the festival.

## For Regular Users

You've been invited to help with gear tracking. Here's what you need to know:

### Your Main Tasks

1. **Scan gear as it moves:**
   - Click "Scan QR"
   - Scan code on equipment
   - Select action (Check In, Transit, On Stage, Check Out)

2. **Update locations manually:**
   - Click "Gear List"
   - Find item
   - Click "Change Location"

3. **Report missing items:**
   - Find item in list
   - Click "Report Missing"
   - All users alerted

4. **Check schedule:**
   - Click "Schedule"
   - See when bands perform
   - Click performance to see band's gear

### Quick Tips

- **Can't scan?** Search for item in Gear List instead
- **Multiple items to move?** Use bulk select (checkboxes)
- **Need reminder?** Use Personal Reminders feature
- **See something urgent?** Check Messages section

## Essential Features At-A-Glance

### Home Page Buttons

- **Scan QR:** Scan gear to update status
- **Register:** Add new gear items
- **Gear List:** View and manage all gear
- **Locations:** Add/edit locations (Admin/Owner only)
- **Schedule:** View performances and band gear
- **Messages:** Team announcements
- **Reminders:** Your personal to-do list
- **Stowage:** Plan container packing (Admin/Owner only)
- **User Management:** Invite users (Owner only)

### Status Dashboard (Top of Page)

Real-time counts:
- **Active:** Gear in specific locations
- **Transit:** Gear being moved
- **On Stage:** Gear currently performing
- **Checked Out:** Gear with bands
- **Missing:** Gear reported lost (click to view)

### Gear Status Badges

- **In Transit:** Yellow badge
- **On Stage:** Green badge
- **Checked Out:** Blue badge
- **Missing:** Red pulsing badge (alerts all users)

## Common First-Day Workflows

### Bulk Gear Registration (Pre-Festival)

**Scenario:** Pre-register all band gear before festival starts

**Steps:**
1. Prepare CSV file: `Band Name, Item Description`
2. Click "Bulk Upload"
3. Select CSV format (Basic)
4. Choose file
5. Select initial location: "Tags Not Collected"
6. Confirm import
7. Print all QR codes
8. Attach to equipment as bands arrive

**As bands arrive and collect tags:**
- Scan each item
- Change location to "Band Registration Area"
- Or use bulk location change

### Band Arrival Registration

**Scenario:** Band arrives with equipment

1. Click "Register"
2. Enter band name (from schedule autocomplete)
3. Use "Quick Add Instruments" or type manually
4. Select "Band Registration Area"
5. Submit registration
6. Print QR codes immediately
7. Attach codes to equipment
8. Scan gear to "Storage" or "Check Out to Band"

### Moving Gear to Stage

**Scenario:** Band about to perform

1. Click "Schedule"
2. Find band's performance
3. Click to view all band gear
4. Note current locations
5. Go to gear in storage
6. Scan items (or bulk select in Gear List)
7. Mark "In Transit"
8. Move to stage
9. Scan again at stage
10. Mark "On Stage"

### Post-Performance

**Scenario:** Band finished performing

**Option 1: Return to Storage**
1. Scan items at stage
2. Select "Check In"
3. Choose storage location

**Option 2: Band Takes Gear**
1. Scan items
2. Select "Check Out to Band"
3. Band takes equipment

### End of Festival

1. Scan all gear as "Check Out to Band"
2. Or leave in "Checked Out" status
3. Bands collect equipment
4. Missing items remain flagged for follow-up

## Tips for Success

### For Owners

- **Add locations before registering gear** (easier workflow)
- **Assign 2-3 admins** (backup if you're unavailable)
- **Use descriptive location names** (not "Area 1", "Location A")
- **Upload schedule early** (auto-links to gear)
- **Train admins before festival** (reduces day-of issues)

### For Admins

- **Print QR codes immediately** after registration
- **Use bulk operations** for efficiency (select all, move all)
- **Report missing items promptly** (increases recovery)
- **Check status dashboard** regularly
- **Use stowage planning** for truck loading

### For All Users

- **Scan often** (keeps status current)
- **Use search if can't scan** (manual fallback)
- **Check messages daily** (important updates)
- **Report issues immediately** (don't wait)
- **Works offline** (no internet? No problem!)

## What If Things Go Wrong?

### Can't Scan QR Code
- Check camera permissions
- Try better lighting
- **Fallback:** Search item in Gear List and update manually

### Item Missing
1. Click "Report Missing"
2. All users alerted
3. When found, scan or click "Found It"

### Wrong Location Assigned
- No problem! Just scan again or change location manually
- System tracks history (audit trail)

### User Can't Access Feature
- Check their role (User vs Admin vs Owner)
- Owner can change roles in User Management

### Changes Not Appearing
- Wait 60 seconds (auto-sync)
- Refresh page (pull down or F5)
- If offline, changes queue and sync when online
