## Pre-Festival Workflows

### Workflow 1: Complete Festival Setup (Owner)

**Timeline:** 2 weeks before festival

**Scenario:** You're setting up the Festival Gear Tracker for the first time.

**Steps:**

**Week 1:**

1. **Create Festival** (5 minutes)
   - Sign up for account
   - Enter festival details
   - Submit creation form
   - Two default locations created automatically

2. **Create Locations** (10 minutes)
   - Click "Locations"
   - Add location for each stage/area:
     - Main Stage (Blue, 🎸)
     - Acoustic Stage (Green, 🎤)
     - Electronic Stage (Purple, 🎹)
   - Add storage locations:
     - Secure Storage (Gray, 📦)
     - Loading Dock (Orange, 🚛)
   - Save each location

3. **Upload Schedule** (5 minutes)
   - Prepare CSV: `Band Name, Location, Date (DD-MM-YYYY), Time (HH:MM)`
   - Click "Schedule" → "Upload CSV"
   - Select file
   - Review preview
   - Confirm import

4. **Invite Team** (10 minutes)
   - Prepare CSV: `Name, Email, Role`
   - Click "User Management" → "Bulk Upload CSV"
   - Select file
   - Review users
   - Confirm import
   - Users receive emails

**Week 2:**

5. **Test System** (30 minutes)
   - Register test gear item
   - Print QR code
   - Test scanning with phone
   - Move item between locations
   - Delete test item
   - Verify admins can access

6. **Bulk Register Gear** (1-2 hours)
   - Collect gear lists from bands
   - Prepare CSV: `Band Name, Item Description`
   - Click "Bulk Upload"
   - Select CSV
   - Assign to "Tags Not Collected"
   - Confirm import

7. **Print All QR Codes** (30 minutes)
   - Click "Print QR Codes" on success screen
   - Choose "Small Tags" layout
   - Print labels
   - Organize by band
   - Store safely

8. **Post Welcome Message** (2 minutes)
   - Click "Messages" → "Post New Message"
   - Category: Announcement
   - Write: "Welcome to [Festival Name]! Please check Messages daily for updates. Contact [your name] for issues."
   - Post message

**Result:** Festival fully set up, ready for band arrivals.

### Workflow 2: Bulk Gear Pre-Registration

**Timeline:** 1-2 days before festival

**Scenario:** Pre-register all known band gear before bands arrive.

**Steps:**

1. **Collect Gear Lists** (varies)
   - Email all bands requesting gear lists
   - Provide template: Band Name | Item Description
   - Set deadline (3 days before festival)
   - Collect responses

2. **Prepare Master CSV** (30 minutes)
   ```csv
   Band Name, Item Description
   The Rockers, Guitar
   The Rockers, Bass Guitar
   The Rockers, Drum Kit
   The Rockers, Amplifier
   Jazz Masters, Saxophone
   Jazz Masters, Keyboard
   Jazz Masters, Monitor Speakers
   Folk Trio, Acoustic Guitar
   Folk Trio, Mandolin
   Folk Trio, Microphone x3
   ```
   - Combine all band lists
   - Use consistent band names
   - Be specific with descriptions
   - Include quantities if multiple items

3. **Upload Bulk CSV** (5 minutes)
   - Click "Bulk Upload"
   - Select "Basic" format
   - Choose CSV file
   - Select location: "Tags Not Collected"
   - Preview shows all items
   - Confirm import

4. **Print QR Codes** (1 hour)
   - Click "Print QR Codes"
   - Choose "Small Tags"
   - Print all labels
   - Organize labels:
     - Sort by band name
     - Put in labeled envelopes
     - Store in order

5. **Set Up Distribution** (30 minutes)
   - Create band registration table
   - Arrange envelopes alphabetically
   - Prepare:
     - Tape/stickers for attaching labels
     - Markers for additional notes
     - Sign-in sheet
     - Staff schedule

6. **Post Reminder Message** (2 minutes)
   - Messages → Post New
   - Category: Announcement
   - "All bands: Please collect your gear tags from Registration. Attach to ALL equipment before bringing to venue."
   - Pin to top

**Result:** All known gear pre-registered with QR codes ready for distribution.

### Workflow 3: Stowage Planning for Transport

**Timeline:** 3 days before festival

**Scenario:** Planning how to pack two trucks with all festival equipment.

**Steps:**

1. **Create Containers** (10 minutes)

   **Truck 1:**
   - Click "Stowage" → "New Container"
   - Name: "Truck 1 - Sound Equipment"
   - Length: 20 feet
   - Width: 8 feet
   - Height: 3 layers
   - Location: "Loading Dock"
   - Save

   **Truck 2:**
   - Name: "Truck 2 - Band Gear"
   - Length: 16 feet
   - Width: 8 feet
   - Height: 2 layers
   - Location: "Loading Dock"
   - Save

2. **Plan Truck 1 (Sound Equipment)** (30 minutes)
   - Click "View" on Truck 1 container
   - Canvas opens

   **Layer 0 (Ground):**
   - Drag large speakers onto canvas
   - Position near back (unload first)
   - Add dimensions: 3ft x 3ft x 2 layers
   - Add mixing board: 4ft x 2ft x 1 layer
   - Add amplifiers: 2ft x 2ft x 1 layer

   **Layer 1:**
   - Switch to Layer 1 in selector
   - Add monitor speakers
   - Add smaller equipment
   - Fill gaps efficiently

   **Layer 2:**
   - Switch to Layer 2
   - Add cables (light items)
   - Add microphone cases
   - Add small boxes

3. **Plan Truck 2 (Band Gear)** (45 minutes)
   - Click "View" on Truck 2 container

   **Layer 0:**
   - Organize by band (color-coded)
   - The Rockers gear (red):
     - Drum kit: 5ft x 5ft x 2 layers
     - Amps: 2ft x 2ft x 1 layer
     - Guitar cases: 4ft x 1.5ft x 1 layer
   - Jazz Masters gear (blue):
     - Keyboard: 4ft x 2ft x 1 layer
     - Sound equipment: 3ft x 3ft x 1 layer
   - Folk Trio gear (green):
     - Instrument cases: position near door (perform first)

   **Layer 1:**
   - Smaller items stacked on sturdy base
   - Personal band equipment
   - Merch boxes

4. **Screenshot Plans** (5 minutes)
   - Take screenshot of each truck plan
   - Save to phone/tablet
   - Print copies for loading crew
   - Email to logistics team

5. **Post Loading Instructions** (5 minutes)
   - Messages → Post New
   - Category: Announcement
   - "Loading Day [date] at 8am. Stowage plans available at loading dock. Load Truck 1 first, then Truck 2. Questions: [contact]"
   - Pin message

**Result:** Detailed visual packing plans ready for efficient loading day.

## Day-Of-Festival Workflows

### Workflow 4: Band Arrival Registration

**Timeline:** Festival Day 1, throughout the day

**Scenario:** Bands arrive with equipment throughout the day. Register gear, distribute QR codes, manage check-in.

**Registration Station Workflow:**

**For Each Band:**

1. **Welcome Band** (1 minute)
   - Greet band at registration desk
   - Verify band name (check schedule)
   - Explain QR code system:
     - "We'll attach a QR code to each piece of your equipment"
     - "Staff will scan codes when gear moves locations"
     - "You can track your gear through our system"

2. **Two Options:**

   **Option A: Pre-Registered (QR codes ready)**
   - Find band's envelope with QR codes
   - "Here are your gear tags"
   - Provide tape/stickers
   - "Please attach these to all your equipment before unloading"
   - Scan each item as band attaches tags:
     - Scan QR code
     - Change location from "Tags Not Collected" to "Band Registration Area"
   - Give band copy of gear list

   **Option B: Not Pre-Registered (register now)**
   - Click "Register" on device
   - Enter band name
   - List items as band describes:
     - Use "Quick Add Instruments" for common items
     - Type descriptions for unique items
     - Add all items at once
   - Select "Band Registration Area"
   - Click "Register Items"
   - Print QR codes immediately
   - Provide to band with tape
   - Help attach if needed

3. **Determine Next Step** (1 minute)

   Ask band: "What would you like to do with your gear?"

   **Option 1: Band Keeps Gear**
   - Select all band's items
   - Click "Check Out to Band"
   - Explain: "When you need storage, bring gear back and we'll check it in"

   **Option 2: Gear Goes to Storage**
   - Ask which items to store
   - Scan each item
   - Select "Secure Storage" location
   - Give band claim ticket (optional)

   **Option 3: Gear Stays at Registration (Performing Soon)**
   - Keep at "Band Registration Area"
   - Explain: "We'll move this to [stage] when it's time for your set"

4. **Provide Information** (1 minute)
   - Give band schedule printout
   - Explain gear retrieval process
   - Provide contact for questions
   - Show them to green room/accommodation

5. **Log in System** (30 seconds)
   - Verify all items scanned or registered
   - Check status dashboard (should show correct count)
   - Post message if any issues

**Continuous Throughout Day:**
- Monitor registration queue
- Keep QR code printer loaded
- Replenish tape/stickers
- Answer questions
- Post updates on wait times

**Example Message:**
"Registration line ~20 min wait. Have your gear list ready to speed things up. Thanks for your patience!"

### Workflow 5: Managing Storage Throughout Day

**Timeline:** Throughout festival

**Scenario:** Bands checking gear in and out of storage throughout the day.

**Storage Station Workflow:**

**Equipment Setup:**
- Scanner device ready
- Storage area organized by band
- Clear signage
- Staff member monitoring

**Band Wants to Store Gear:**

1. **Scan All Items** (2 minutes)
   - Open scanner
   - Scan each item band brings
   - For each scan:
     - Select "Check In"
     - Choose "Secure Storage"
   - Items update immediately

2. **Physical Organization** (3 minutes)
   - Place band's gear together
   - Use color coding from system
   - Mark area with band name
   - Note fragile items

3. **Confirm with Band** (30 seconds)
   - "All [number] items checked into storage"
   - "Retrieve anytime, just show up with ID"
   - Note claim process if needed

**Band Wants to Retrieve Gear:**

1. **Verify Band** (30 seconds)
   - Ask band name
   - Check ID if needed
   - Open Gear List
   - Filter by band name

2. **Locate Items** (2 minutes)
   - Check current location (should show "Secure Storage")
   - Go to band's area in storage
   - Count items

3. **Check Out Gear** (2 minutes)
   - Scan each item
   - Select "Check Out to Band"
   - Or if going to stage: Select stage location
   - Verify count matches

4. **Confirm** (30 seconds)
   - "All [number] items checked out"
   - Band takes gear
   - Status updates immediately

**Proactive Monitoring:**

**Every Hour:**
- Check status dashboard
- Review items in storage
- Organize as needed
- Post message if storage filling up

**Before Each Performance:**
- Check schedule for upcoming bands
- View their gear status
- If in storage, prepare for retrieval
- Post reminder message

**Example Message:**
"The Rockers performing in 30 mins at Main Stage. Gear currently in Secure Storage. Please retrieve now."

### Workflow 6: Check-In Scanning Station

**Timeline:** Throughout festival

**Scenario:** Central scanning station where staff scan gear as it moves locations.

**Station Setup:**
- Multiple devices with scanners ready
- Clear signage: "Gear Check-In Station"
- Queue management
- Staff rotation schedule

**Standard Check-In Process:**

1. **Greet User** (10 seconds)
   - "Hi! Band name?"
   - "Moving gear to or from?"

2. **Scan Items** (1-2 minutes)
   - Open scanner
   - Scan first item
   - Item details appear
   - Ask: "Where is this going?"
   - Options:
     - Specific location (Main Stage, Storage, etc.)
     - In Transit
     - On Stage
     - Check Out to Band
   - Select appropriate action
   - Repeat for each item

3. **Bulk Operations for Multiple Items** (faster)
   If many items going same place:
   - Scan all items quickly
   - Note display IDs
   - Switch to Gear List
   - Search for items by display ID
   - Select all
   - Click "Change Location"
   - Select destination
   - Confirm

4. **Confirm Action** (10 seconds)
   - "[Number] items checked in to [location]"
   - "You're all set!"

**Special Cases:**

**Item Not in System:**
- "I don't see that item registered. Let's add it."
- Click "Register"
- Enter band name and description
- Select location
- Register and print QR code
- Attach to item

**QR Code Damaged/Missing:**
- "Can you describe the item?"
- Search Gear List by band + description
- Find item manually
- Change location directly
- Print new QR code
- Replace damaged one

**Item Reported Missing:**
- Scanner shows "This item was reported missing!"
- "Great! Where did you find this?"
- Select found location
- System resolves missing status automatically
- Post message: "Missing item [description] found!"

## Performance Workflows

### Workflow 7: Pre-Performance Gear Preparation

**Timeline:** 30-60 minutes before each performance

**Scenario:** Prepare band's gear for their set, move to stage, ensure everything ready.

**Crew Workflow:**

1. **Check Schedule** (2 minutes)
   - Open Schedule page
   - Find next performance
   - Note:
     - Band name
     - Stage location
     - Performance time
     - Current time (how much time?)

2. **View Band's Gear** (1 minute)
   - Click on performance in schedule
   - Modal shows all band gear
   - Note current locations:
     - In storage?
     - Checked out to band?
     - Already on stage?
     - In transit?
   - Count total items

3. **Retrieve from Storage** (5-10 minutes)
   - If gear in storage:
     - Go to storage location
     - Find band's gear
     - Load onto cart/dolly
   - If checked out to band:
     - Find band in green room
     - Coordinate pickup
     - Assist if needed

4. **Mark In Transit** (1 minute)
   **Option A: Scan items**
   - Scan each item
   - Select "In Transit"

   **Option B: Bulk operation**
   - Gear List → Filter by band
   - Select all items
   - Click "Mark In Transit"
   - Status updates for all

5. **Transport to Stage** (5 minutes)
   - Move gear carefully
   - Check fragile items
   - Coordinate with stage crew

6. **Set Up on Stage** (10-20 minutes)
   - Place items per band's instructions
   - Sound check assistance
   - Final positioning

7. **Mark On Stage** (1 minute)
   **Option A: Scan all**
   - Scan each item
   - Select "On Stage"

   **Option B: Bulk**
   - Gear List → Filter by band + In Transit
   - Select all
   - Click "Mark On Stage"
   - Status updates immediately

8. **Verify Complete** (30 seconds)
   - Check schedule view
   - All items should show "On Stage"
   - If any missing, investigate
   - Post message if issue

9. **Post Confirmation** (1 minute)
   - Messages → Post New
   - Category: Info
   - "[Band Name] gear ready at [Stage]. [Number] items on stage. Set starts [time]."

**Result:** Band's gear ready on stage, all items tracked, crew can prepare next band.

### Workflow 8: Post-Performance Gear Breakdown

**Timeline:** Immediately after performance

**Scenario:** Band finishes, need to clear stage for next act, manage gear return.

**Two Common Scenarios:**

### Scenario A: Band Keeps Gear

**Steps:**

1. **Coordinate with Band** (1 minute)
   - "Do you want to take your gear or store it?"
   - If taking: "We'll check it out to you"

2. **Scan Items** (2 minutes)
   - Scan each item as band packs
   - Select "Check Out to Band"
   - Items update to "Checked Out" status

3. **Band Takes Gear** (5 minutes)
   - Band loads to vehicle/green room
   - Crew assists if needed
   - Verify all items scanned

4. **Confirm** (30 seconds)
   - Check Gear List
   - All items should show "Checked Out"
   - Status dashboard updates
   - Done

### Scenario B: Return to Storage

**Steps:**

1. **Pack Up** (5 minutes)
   - Band or crew packs gear
   - Load onto cart
   - Check for left items (cables, etc.)

2. **Mark In Transit** (1 minute)
   - Bulk select all band items
   - Click "Mark In Transit"
   - Or scan each individually

3. **Transport to Storage** (5 minutes)
   - Move to storage area
   - Find band's designated space

4. **Check Into Storage** (2 minutes)
   - Scan each item
   - Select "Secure Storage"
   - Or bulk location change
   - Items update immediately

5. **Organize** (2 minutes)
   - Place items in band's area
   - Keep together
   - Note fragile items

6. **Confirm** (30 seconds)
   - Verify all items scanned
   - Status dashboard shows correct count
   - Done

**If Band Performing Again:**
- Keep gear backstage or nearby stage
- Don't check out or move to distant storage
- Mark as "Stage Storage" location (if created)
- Easy access for next performance

## Problem Resolution Workflows

### Workflow 9: Lost Item Recovery

**Timeline:** When item reported missing

**Scenario:** Item cannot be located. Staff and band work to recover it.

**Step 1: Report Missing** (1 minute)

**Who:** Anyone who notices item missing

1. Open Gear List
2. Find item
3. Click item to open detail
4. Click "Report Missing"
5. Confirm alert
6. System records:
   - Who reported
   - When reported
   - Last known location

**System Response:**
- Message bar shows pulsing red alert
- "⚠️ X items missing - View"
- All users see alert
- Item gets red pulsing badge

**Step 2: Alert Team** (2 minutes)

**Admin posts message:**
1. Messages → Post New
2. Category: Alert
3. Content:
   ```
   ⚠️ MISSING: [Item description] for [Band Name] (ID: [Display ID])
   Last seen: [Location] at [time]
   Reported by: [Person]
   Please check: [likely locations]
   Contact [admin] if found.
   ```
4. Pin message
5. Post

**Step 3: Systematic Search** (15-30 minutes)

**Coordinated search:**
- Assign team members to specific areas
- Check last known location thoroughly
- Check nearby areas
- Check stage areas
- Check storage
- Check loading dock
- Check lost & found
- Ask band members

**Search Locations:**
1. Last scanned location (priority)
2. Previous location (before last)
3. Nearby locations
4. Common "left behind" spots:
   - Under stages
   - In cases/bags
   - Behind equipment
   - Green room
   - Parking area

**Step 4: Item Found - Recovery** (2 minutes)

**Option A: Found via Scan**
1. Finder scans QR code
2. System shows: "This item was reported missing!"
3. Select location where found
4. System automatically:
   - Resolves missing status
   - Records who found it
   - Records where found
   - Updates status to active
   - Removes from missing count

**Option B: Found Manually (No Scan)**
1. Finder reports to admin
2. Admin opens item detail
3. Click "Found It" button
4. Select location where found
5. System records recovery
6. Status resolves

**Step 5: Update Team** (1 minute)

**Admin posts message:**
1. Messages → Post New
2. Category: Announcement
3. "✓ FOUND: [Item description] for [Band Name]. Located at [location]. Thanks everyone!"
4. Delete or unpin original missing alert

**Step 6: Notify Band** (1 minute)
- Contact band directly
- "We found your [item]"
- "It's now in [location]"
- "You can retrieve it anytime"

**Result:** Item recovered, status updated, team and band notified.

### Workflow 10: QR Code Damaged or Missing

**Timeline:** When code unreadable

**Scenario:** QR code damaged, wet, torn, or missing from equipment.

**Option A: Print Replacement Code**

**Steps:**

1. **Identify Item** (1 minute)
   - Ask for item details (band name, description)
   - Open Gear List
   - Search by band + description
   - Find correct item
   - Note display ID

2. **Print New QR Code** (2 minutes)
   - Click item in Gear List
   - Click "Print QR Code"
   - Choose layout (Small Tag or Large)
   - Print code

3. **Attach Replacement** (1 minute)
   - Remove old damaged code if present
   - Attach new code to item
   - Ensure secure attachment
   - Use clear tape if weather concerns

4. **Test Scan** (30 seconds)
   - Scan new code
   - Verify correct item appears
   - Update location if needed

**Option B: Manual Update (No Printer Available)**

**Steps:**

1. **Identify Item** (1 minute)
   - Get description from band/user
   - Search Gear List
   - Find item

2. **Update Manually** (30 seconds)
   - Click item
   - Click "Change Location"
   - Select destination
   - Confirm

3. **Note for Later** (1 minute)
   - Add reminder to print code later
   - Or temporarily mark item
   - Add to to-do list for end of shift

**Option C: Item Not in System at All**

**Steps:**

1. **Register Item Now** (2 minutes)
   - Click "Register"
   - Enter band name
   - Enter item description
   - Select current location
   - Submit registration

2. **Print QR Code** (2 minutes)
   - Print code immediately
   - Attach to item

3. **Scan to Verify** (30 seconds)
   - Scan new code
   - Confirm correct item/location

**Prevention:**
- Use waterproof tape
- Print on weather-resistant labels
- Laminate codes for outdoor festivals
- Attach securely (zip ties for flight cases)
- Have backup codes printed for expensive items

### Workflow 11: Multiple Items Missing After Performance

**Timeline:** Immediately after discovering multiple items gone

**Scenario:** After band's set, several items cannot be located. Possible theft or misplacement.

**Step 1: Verify Missing** (5 minutes)

1. Open Schedule → Find performance
2. Click to view all band gear
3. Check status of each item:
   - Some show "On Stage"
   - Others unclear
4. Ask stage crew:
   - "Did band take any gear?"
   - "Was gear moved somewhere?"
5. Check backstage storage
6. Check band's green room/vehicle

**Step 2: Report All Missing** (3 minutes)

**For each item not located:**
1. Open item in Gear List
2. Click "Report Missing"
3. Confirm

**System now shows:**
- Multiple items in missing status
- Red pulsing alert: "⚠️ 5 items missing"
- All staff alerted

**Step 3: Post Urgent Message** (2 minutes)

**If high-value or many items:**
1. Messages → Post New
2. Category: Urgent (if valuable) or Alert
3. Content:
   ```
   ⚠️ MULTIPLE ITEMS MISSING

   [Number] items for [Band Name] cannot be located after their set at [Stage] [time ago].

   Missing items:
   - [Item 1] (ID)
   - [Item 2] (ID)
   - [Item 3] (ID)

   Last seen: [Stage] at [time]

   ALL STAFF: Check your areas immediately.
   Possible locations: Backstage, green room, parking, adjacent stage.

   Contact [admin name] IMMEDIATELY if found.

   Security notified.
   ```
4. Post (creates popup for all users)

**Step 4: Coordinate Search** (20-40 minutes)

**Assign search teams:**
- Team 1: Performance area (stage, backstage, wings)
- Team 2: Storage areas (all storage locations)
- Team 3: Common areas (green room, bathrooms, parking)
- Team 4: Contact band members

**Search Protocol:**
1. Check last known location thoroughly
2. Expand to nearby areas
3. Check behind/under equipment
4. Check locked areas (get keys)
5. Review scan history for clues
6. Check adjacent stages (might have been moved)

**Step 5: Notify Stakeholders** (5 minutes)

**Contact:**
- Festival security
- Stage managers
- Other admins/owner
- Band contact directly
- Insurance (if valuable)

**Provide Info:**
- Item descriptions
- Last known location
- Timeline
- Pictures if available

**Step 6: Resolution** (varies)

**Items Found:**
1. Scan each item or use "Found It"
2. Select location found
3. Post update message
4. Notify band
5. Document incident

**Items Not Found:**
1. File report with security
2. Document for insurance
3. Keep items in "Missing" status
4. Follow up with band
5. Post-festival follow-up

**Step 7: Post-Incident Review** (after festival)

**Analyze:**
- How did items go missing?
- Were they checked out?
- Last scan time?
- Who was responsible?
- How to prevent in future?

**Improve:**
- Better checkout process?
- More frequent scans?
- Designated gear area?
- Additional staff?

## Post-Festival Workflows

### Workflow 12: End-of-Festival Checkout

**Timeline:** Last day of festival, final hours

**Scenario:** Festival ending, all bands retrieving gear, mass checkout operation.

**Setup: Final Checkout Station** (30 minutes before)

**Equipment:**
- Multiple scanning devices
- Staff assigned
- Checkout list printed
- Clear signage
- Queue management

**Process for Each Band:**

1. **Band Arrives** (30 seconds)
   - "Hi! Band name?"
   - Check them in
   - "We'll help you find all your gear"

2. **Review Band's Gear** (1 minute)
   - Open Gear List
   - Filter by band name
   - Show band the list on screen:
     - "Here are all your [number] items"
     - "Currently located in: [locations]"

3. **Retrieve Gear** (10 minutes)
   - If in storage:
     - Escort band to storage area
     - Help gather items
     - Load onto cart
   - If multiple locations:
     - Coordinate retrieval
     - May need multiple trips

4. **Scan Out Items** (3 minutes)
   - As band loads gear:
     - Scan each item
     - Select "Check Out to Band"
   - Or bulk checkout:
     - Select all band items
     - Click "Check Out to Band"
     - Confirm

5. **Verify Complete** (2 minutes)
   - Count physical items
   - Check against list
   - All items accounted for?

6. **Missing Items?**
   - If items not found:
     - Note which items
     - Check if already checked out
     - Check if reported missing
     - Provide contact info for follow-up
     - Document incident

7. **Confirm and Thank** (1 minute)
   - "All [number] items checked out"
   - "Thank you for performing!"
   - Provide festival contact for follow-up
   - Wish safe travels

**Continuous Throughout Checkout:**

**Monitor Progress:**
- Dashboard shows checked-out count increasing
- Track which bands complete
- Note any issues
- Post updates

**Post Regular Updates:**
```
"Checkout Station: Current wait time ~15 mins. Please have band name ready."
```

```
"Reminder: All gear must be claimed by [time]. Unclaimed items will be stored at [location]."
```

**Handle Stragglers:**
- Some bands leave early
- Some bands forget items
- Some items unclaimed

**For Unclaimed Gear:**
1. Post message with deadline
2. After deadline, photograph items
3. Move to secure storage
4. Document:
   - Item description
   - Display ID
   - Band name
   - Photos
5. Contact band
6. Arrange shipping/pickup if needed

### Workflow 13: Post-Festival Cleanup and Review

**Timeline:** 1-7 days after festival

**Scenario:** Festival over, clean up data, review what worked, prepare for next time.

**Day 1 After: Immediate Tasks** (2 hours)

1. **Check for Unclaimed Gear** (30 minutes)
   - Open Gear List
   - Filter by status: Active (not checked out)
   - Items still showing in locations?
   - Contact those bands
   - Arrange pickup or shipping

2. **Review Missing Items** (30 minutes)
   - Filter by status: Missing
   - Were any found after festival?
   - Contact bands about missing items
   - File insurance claims if needed
   - Document for records

3. **Export Data** (15 minutes)
   - Currently no built-in export (future feature)
   - Screenshot important data:
     - Final gear counts
     - Missing items list
     - Total registrations
     - User list
   - Save locally as backup

4. **Post Thank-You Message** (5 minutes)
   - Messages → Post New
   - Category: Announcement
   - "Festival complete! Thank you all staff for excellent work. Please return scanning devices to [location]. Final meeting [date/time]."
   - Post

5. **Return Equipment** (varies)
   - Collect all scanning devices
   - Unused QR code stickers
   - Other equipment
   - Return to owner

**Week After: Review and Improve** (1-2 hours)

**Data Review:**

1. **Usage Statistics** (manual count)
   - Total gear items registered: [count]
   - Total bands: [count]
   - Total scans: [view scan history]
   - Total staff users: [count]
   - Missing items reported: [count]
   - Missing items recovered: [count]

2. **Problem Analysis**
   - What went wrong?
   - Common issues:
     - Scanning problems?
     - Missing items?
     - User confusion?
     - Technical issues?
   - Document each

3. **Success Analysis**
   - What went well?
   - Efficient workflows?
   - Features heavily used?
   - Staff feedback positive?
   - Band feedback?

**Team Debrief:**

1. **Schedule Meeting** (1 hour)
   - All admins and key staff
   - In person or video call

2. **Agenda:**
   - Review statistics
   - Discuss problems
   - Celebrate successes
   - Gather feedback:
     - What would you change?
     - What features needed?
     - What training needed?
   - Document suggestions

3. **Create Improvement Plan:**
   - List changes for next festival
   - Assign responsibilities
   - Set timelines
   - Update documentation

**Cleanup Tasks:**

1. **User Management** (if one-time event)
   - Remove users who won't return
   - Keep core team
   - Or leave as-is if same team next year

2. **Data Archiving** (future feature)
   - Currently: Data stays in Firebase
   - Can create new festival for next year
   - Historical data preserved

3. **Documentation:**
   - Save this festival's workflow notes
   - Update procedures for next time
   - Share with next year's team

**Follow-Up:**

1. **Band Communications**
   - Final follow-up on missing items
   - Request feedback on gear tracking
   - Keep contact info for next year

2. **Financial**
   - Process any claims
   - Settle any disputes
   - Review costs vs. benefits

3. **Next Festival Planning**
   - If annual event, plan kickoff date
   - Review and update procedures
   - Consider system improvements
