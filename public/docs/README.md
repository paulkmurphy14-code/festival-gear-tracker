## How to Use This Documentation

### For New Users

**Day 1:**
1. Read [Quick Start Guide](QUICK_START.md) (5-10 minutes)
2. Try the basic workflows
3. Refer back as needed

**Week 1:**
1. Skim [User Guide](USER_GUIDE.md) to understand features
2. Refer to specific sections as you use features
3. Check [FAQ](FAQ.md) for common questions

### For Admins/Owners

**Pre-Festival:**
1. Read [Admin Guide](ADMIN_GUIDE.md) completely
2. Review [Workflows](WORKFLOWS.md) for setup procedures
3. Follow pre-festival workflows
4. Set up system using guides

**During Festival:**
1. Keep [Quick Start Guide](QUICK_START.md) handy for reference
2. Use [Workflows](WORKFLOWS.md) for specific scenarios
3. Check [FAQ](FAQ.md) for quick answers

**Post-Festival:**
1. Follow post-festival workflows in [Workflows](WORKFLOWS.md)
2. Review [Admin Guide](ADMIN_GUIDE.md) best practices
3. Document improvements for next time

### For Training

**Quick Training (30 minutes):**
- Use [Quick Start Guide](QUICK_START.md)
- Demonstrate basic features
- Practice with test items

**Full Training (2-3 hours):**
- Cover [User Guide](USER_GUIDE.md) sections
- Walk through [Workflows](WORKFLOWS.md) examples
- Hands-on practice
- Q&A using [FAQ](FAQ.md)
